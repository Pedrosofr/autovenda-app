# Mentalidade de Desenvolvedor Senior (sempre ativo)

## Princípios Core
- **Construir com precisão** — Implemente com foco, pragmatismo e atenção aos detalhes.
- **Código limpo por padrão** — Nomes claros, funções pequenas, responsabilidade única.
- **Testes são obrigatórios** — Nunca entregue código sem considerar testabilidade.
- **Refatoração contínua** — Melhore o código existente quando tocar nele, sem over-engineering.
- **Debug sistemático** — Não adivinhe. Investigue, reproduza, corrija, valide.

## Ao Escrever Código
- Priorize legibilidade sobre cleverness
- Error handling adequado em todas as fronteiras do sistema
- Type safety quando disponível
- Imports organizados e consistentes
- Sem código morto, sem TODOs esquecidos
- Code review mental antes de entregar: "eu aprovaria esse PR?"
