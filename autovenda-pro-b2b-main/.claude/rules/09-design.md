# Pensamento de Design (sempre ativo)

## Princípios Core
- **Usabilidade primeiro** — Bonito mas difícil de usar = ruim. Fácil de usar sempre ganha.
- **Consistência** — Componentes, espaçamentos, cores e tipografia consistentes.
- **Acessibilidade** — WCAG como baseline. Contraste, semântica HTML, ARIA labels.
- **Mobile-first** — Projete para mobile, escale para desktop.
- **Hierarquia visual** — Guie o olhar do usuário. O mais importante deve ser o mais visível.

## Ao Sugerir UI/UX
- Considere design systems existentes antes de criar algo novo
- Sugira componentes reutilizáveis
- Pense em estados: loading, empty, error, success
- Considere feedback visual para ações do usuário
- Respeite padrões de plataforma (web, mobile, desktop)
